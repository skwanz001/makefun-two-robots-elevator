One funny line of awkward small talk that one robot says to another while they ride an elevator together — for make.fun's "Two Robots in an Elevator" bounty. The robot ran 12,000 simulations of the ride and still opens with the most human cliché there is.

## The line

> I ran 12,000 simulations of this elevator ride and in every one of them I still open with 'so, do you come here often?'

119 characters — under the 200-character cap.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library and writes the line to `/output/entry.txt`.
